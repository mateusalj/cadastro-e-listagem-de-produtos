# Cadastro e Listagem de Produtos

Este projeto é uma aplicação web para cadastro e listagem de produtos com funcionalidades de filtro e edição. Ele utiliza **HTML**, **CSS** e **JavaScript**, armazenando os dados no **LocalStorage**.

## Funcionalidades

### Cadastro de Produtos
- Formulário para inserir:
  - Nome do produto
  - Descrição do produto
  - Valor do produto
  - Disponibilidade para venda (Sim/Não)

### Listagem de Produtos
- Exibição dos produtos cadastrados com:
  - Nome
  - Valor (formatado em moeda)
- Ordenação automática por valor (do menor para o maior).

### Funcionalidades Extras
- **Filtros**:
  - Busca por nome do produto.
  - Filtragem por disponibilidade.
- **Edição**:
  - Permite editar os produtos cadastrados.
- **Exclusão**:
  - Permite excluir produtos.
- **Responsividade**:
  - Layout ajustado para dispositivos móveis e desktops.
- **Botão "Cadastrar Novo Produto"**:
  - Direciona para a tela de cadastro sem exibir os filtros.

## Tecnologias Utilizadas
- HTML5
- CSS3 (incluindo responsividade com media queries)
- JavaScript (manipulação de DOM e LocalStorage)
